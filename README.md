# Campus Lost & Found 🔎

A web-based Campus Lost & Found platform designed to help students report and find lost or found items easily.

## 🚧 Project Status

This project is currently a **work in progress**. More features and improvements are being added.

## 💻 Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Report lost items
- Report found items
- Browse listed items
- Search and filter items
- Contact information for item recovery
- Responsive and user-friendly interface

## 🎯 Future Improvements

- React.js integration
- Backend and database
- User authentication
- Permanent storage of reported items
- Image upload and storage
- Improved search and filtering
